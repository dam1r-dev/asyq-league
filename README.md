# Asyq League — асық ату в браузере

**Цифровая версия казахской игры на меткость асық ату.** Прицелься, выбери силу броска и выбей асыки
из кона сақой. Есть обучение, 12 испытаний с нарастающей сложностью, дуэль вдвоём на одном телефоне,
испытание дня, лига университетов, редактор расстановок со ссылкой для друга и магазин косметики
в тестовом режиме.

- **Играть:** https://asyq-league.vercel.app
- **Тестовый аккаунт:** логин `demo`, пароль `asyq2026` (на странице входа есть кнопка «Войти как demo»)
- Играть можно и без регистрации: прогресс сохранится в браузере.

> Работа для технического этапа Narxoz Incubator 2026 (задание «Асық ату»).

---

## Для кого и зачем

Асық ату знакомо родителям по летним дворам, но многие студенты уже не играли в него сами.
**Asyq League** — это игра для **студентов и школьников Казахстана**, в которую можно сыграть за минуту
с телефона, а потом бороться за свой университет в **лиге вузов**.

Идея продукта: _не просто перенести асыки на экран, а дать повод возвращаться каждый день_.
- **Испытание дня** — одна расстановка для всех. Каждый день в 00:00 по Алматы появляется новая.
- **Лига университетов** — лучшие результаты студентов в испытаниях дня суммируются в очки вуза за неделю.
  Вузу выгодно, чтобы играли многие и каждый день, а не один сильный игрок.
- **Вызов другу** — любую расстановку со своим результатом можно отправить ссылкой. Друг играет ту же
  задачу, и сравниваются очки.

## Правила

### Поле
- **Кон** — меловой круг, внутри которого стоят асыки (чаще всего в ряд, как во дворе).
- **Сақа** — биток игрока: крупный асык. В игре она в 2,5 раза тяжелее обычного асыка (во дворе сақу
  заливали свинцом).
- **Линия броска** — сақа бросается из-за неё. Место на линии можно выбрать.

### Порядок действий
1. При желании сдвинь сақа вдоль линии кнопками ◀ ▶ (или стрелками на клавиатуре).
2. Коснись поля и **потяни назад, как рогатку**: направление задаёт угол, длина — силу (до 100%).
3. Пунктир показывает путь сақа до первого удара или точку, где она остановится. Что будет после удара,
   решает физика.
4. Отпусти. Когда всё остановится, начисляются очки, а сақа возвращается на линию.
5. Если потянуть «назад к себе», надпись станет красной и бросок не состоится.

### Очки
| Событие | Очки |
|---|---|
| Асык **полностью** за меловой линией кона | **+1** |
| Выбил несколько за один бросок — за каждый сверх первого ✦ | **+1** |
| Сақа остановилась внутри кона (как «айып» во дворе) | **−1** |
| Кон очищен — за каждый неиспользованный бросок ✦ | **+2** |

Выбитый асык сразу удаляется из состояния раунда, поэтому **очки за него невозможно получить дважды**.
Счёт не опускается ниже нуля.

### Победа
- **Испытания и испытание дня:** выбей все асыки до того, как кончатся броски. Уложился в норму — ⭐⭐⭐,
  чуть больше бросков — ⭐⭐, иначе ⭐ ✦. Звёзды открывают следующее испытание.
- **Дуэль (Екеуара):** двое бросают по очереди по общему кону из 11 асыков, у каждого 8 бросков.
  **Выбил асык и сақа не осталась в коне — бросаешь ещё раз** (дворовое правило). Игра идёт, пока кон
  не опустеет или не кончатся броски. Побеждает тот, у кого больше очков.
- **Вызов другу:** одна и та же расстановка, у кого больше очков — тот победил.

### Авторские дополнения (✦)
Отмечены ✦ выше и значком «авторское» в самом приложении:
- комбо-бонус, бонус за оставшиеся броски, звёзды;
- камни-препятствия на части испытаний;
- испытание дня, лига вузов, редактор расстановок и вызов по ссылке;
- показ стороны, которой упал выбитый асык (алшы, тәйкі, бүк, шік). Это только атмосфера, на очки
  не влияет.

## Как игра адаптирована для браузера

- **Вид сверху, сақа скользит по земле.** Во дворе сақу бросают по воздуху, но на экране так
  невозможно точно целиться пальцем. Скольжение с трением даёт понятную связь «сила ↔ дистанция».
- **Прицел-рогатка** работает одинаково мышью, пальцем и стилусом (Pointer Events). Пунктир до первого
  удара помогает новичку, но не выдаёт результат: разлёт асыков после удара решает физика.
- **Звук и «сочность» броска.** Щелчок кости о кость синтезируется Web Audio, есть тряска экрана,
  частицы пыли, вибрация на телефоне, **замедление времени**, когда асык вылетает за линию, и «+1».
- **Обучение** встроено в первое испытание: подсказки поверх игры, анимированная рука «потяни»,
  советы после каждого броска и итоговый совет после раунда («бросаешь мягко», «встань сбоку и бей
  вдоль ряда»).

## Техническая часть

### Детерминированная физика (своя, ~200 строк)
`src/game/physics.ts` — простой движок для кругов на плоскости:
- фиксированный шаг `1/120 с`, не зависит от FPS;
- трение — постоянное замедление, поэтому тела гарантированно останавливаются в ноль;
- упругие столкновения кругов через импульс по нормали, раздвигание пересекающихся тел, неподвижные камни;
- **используются только `+ − × ÷` и `Math.sqrt`**. По IEEE 754 они дают бит-в-бит одинаковый результат
  в любом браузере и в Node.js. `sin/cos/atan2` такой гарантии не дают, поэтому направление броска
  задаётся вектором `(vx, vy)`, а не углом.

Благодаря детерминированности **бросок полностью описывается тремя числами** `{sx, vx, vy}`:
- **Античит:** клиент отправляет на сервер только броски, а **сервер сам проигрывает раунд** тем же
  кодом и записывает очки, звёзды и победу (`src/lib/verify.ts`). Подделать рекорд правкой запроса
  или localStorage нельзя.
- **Сохранение раунда** — это просто список бросков. После перезагрузки раунд восстанавливается
  реплеем (`replayRound`).
- **Вызов по ссылке** даёт одинаковый результат у обоих игроков.
- **Испытание дня** генерируется из даты детерминированным ГСЧ (mulberry32), поэтому у всех оно
  одинаковое и его не нужно хранить в базе.

Проверено тестами (`npm test`): одинаковый результат повторного броска, отсутствие двойного счёта,
реплей раунда, валидация ссылок и **проходимость каждого уровня и испытаний дня ботом-перебором**.
Сложность уровней калибровалась симуляцией «неточного игрока» со случайной ошибкой прицела и силы.

### Архитектура
```
src/game/        чистый TypeScript без React: физика, правила раунда, уровни, дуэль,
                 испытание дня, ссылки-вызовы, советы, рендер canvas
src/components/  GameCanvas (ввод + анимация), PlayScreen, ResultModal, провайдер аккаунта
src/app/         страницы (App Router) и API-маршруты
src/lib/         Prisma, сессии, проверка попыток, рейтинги, каталог магазина, localStorage, звук
prisma/          схема и миграции
scripts/         применение миграций на Turso, e2e-проверка в браузере
```

### Данные и аккаунты
- **Prisma 7 + libSQL:** локально это файл SQLite, в продакшене — [Turso](https://turso.tech).
  Таблицы `User`, `Attempt` (все сыгранные раунды с бросками), `Purchase`.
- **Авторизация:** логин и пароль (bcrypt), сессия — подписанный JWT (HS256, `jose`) в httpOnly-cookie.
- **Гость → аккаунт:** при входе гостевой прогресс переносится в профиль, и сервер перепроверяет
  каждый результат.
- **Профиль:** звёзды, личные рекорды по уровням, история раундов, университет, снаряжение.
  Всё доступно после входа с любого устройства.
- **Рейтинги:** топ испытания дня, лига университетов (7 дней), мастера (сумма звёзд).

### Монетизация (тестовый режим)
Принцип: **продаём только внешний вид и дополнительный контент, никогда не преимущество.**
Физика одинакова для всех скинов, а платные испытания не входят в рейтинг.
- Скины сақа (Қызыл, Көк, Алтын) и площадки (Ауыл, Дала, Киіз), наборы испытаний («Дала аңыздары» —
  4 уровня).
- Оплата в явном **тестовом режиме**: карта `4242 4242 4242 4242`, деньги не списываются. Сервер
  записывает покупку, и предмет **реально открывается**: скин сразу надевается, уровни набора
  становятся доступны (сервер тоже проверяет покупку перед засчитыванием результата).
- **Дальнейший план (B2B):** «турнирный пакет» для студсоветов, клубов и школ — приватная лига со
  своими расстановками и таблицей. Платит организатор, игроки участвуют бесплатно.

## Запуск локально

```bash
npm install                 # также выполнит prisma generate
cp .env.example .env        # DATABASE_URL="file:./dev.db", AUTH_SECRET=любая длинная строка
npx prisma migrate dev      # создать локальную SQLite-базу
npm run dev                 # http://localhost:3000
npm test                    # тесты физики, правил и баланса уровней
```

### Деплой (Vercel + Turso)
1. Создать базу в Turso и получить URL (`libsql://…`) и токен.
2. В Vercel → Settings → Environment Variables задать `DATABASE_URL`, `TURSO_AUTH_TOKEN`, `AUTH_SECRET`.
3. `npm run build` сначала запускает `scripts/db-apply.mjs`: он накатывает миграции на Turso
   (`prisma migrate deploy` не умеет работать с `libsql://`) и создаёт тестовый аккаунт `demo`.

## Известные ограничения
- Вид сверху и скольжение вместо полёта: это осознанное упрощение для точного управления пальцем.
- Для физики асык — круг, а рисуется «бантиком». Отскок не зависит от того, какой стороной лежит асык.
- Нет онлайн-мультиплеера в реальном времени: вместо него асинхронный вызов по ссылке (детерминизм
  гарантирует одинаковый результат) и дуэль на одном устройстве.
- Интерфейс на русском, названия уровней на казахском. Полноценной казахской и английской локализации пока нет.
- Рейтинги считаются запросами «на лету»: для тысяч игроков понадобится кэш или предрасчёт.
- Оплата только тестовая, реального платёжного провайдера нет.
